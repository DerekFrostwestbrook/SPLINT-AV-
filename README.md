# SPLINT AV

SPLINT is a Windows security scanner with open source FREE and PRO editions.
The repository contains the source code and build SDK for those editions.

## Editions

* **SPLINT MAX product page:** [derekfrostwestbrook.github.io/SPLINT-AV-](https://derekfrostwestbrook.github.io/SPLINT-AV-/) (after GitHub Pages is enabled and the first deployment completes).
* **FREE** is licensed under 0BSD. See [free/LICENSE](free/LICENSE).
* **PRO** is licensed under MIT. Keep its copyright and license notice when
  redistributing copies or substantial portions. See [pro/LICENSE](pro/LICENSE).
* Shared files at the repository root are covered by [LICENSE](LICENSE).
* **MAX** and **MAX-NATIVE** are commercial editions. Their source code and
  release build tools are not included here. See [max/README.md](max/README.md)
  and [native_max/README.md](native_max/README.md) for purchase inquiries.

## Build FREE and PRO

See [SDK.md](SDK.md) for prerequisites, build instructions, and license details.
The build expects a separately supplied SHA-256 database. Database contents and
other third-party data are not included or relicensed by the source licenses.

## Repository contents

This repository contains source and documentation only. Compiled programs,
license server credentials, issued-key records, scan reports, quarantine data,
and local backups are intentionally excluded.
